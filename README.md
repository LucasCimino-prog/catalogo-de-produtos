# CATÁLOGO DE PRODUTOS - API REST com java + Spring Boot

Esta é uma API REST desenvolvida para treinar a aplicação de conceitos do **Java Spring Boot** junto de técnologias do mercado.
O sistema gerencia um catálogo de produtos com cadastro, consulta, atualização e exclusão (CRUD) de produtos, além de conter
formas de segurança por meio do **Spring security** e **JWT** possuí também **testes unitários** e de **integração**.
